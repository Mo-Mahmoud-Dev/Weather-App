# 🌤️ Weather App

A clean, dynamic, and responsive Weather Application built using **Vanilla JavaScript (ES6+)**, **HTML5**, and **CSS3**. The app fetches real-time weather data for any city globally, displaying key metrics alongside contextual weather emojis.

## 🚀 Getting Started
You can visit this website here: <a href="https://code-mo-dev.github.io/Weather-App/">Visit</a>
---

## ✨ Features

* **Global City Search:** Fetch current weather status for any specified city.
* **Comprehensive Details:** Displays:
  * Temperature in Celsius (°C).
  * Humidity percentage.
  * Weather condition description (e.g., Sunny, Cloudy, Rain).
  * Dynamic weather emojis mapped directly to condition codes.
* **Robust Error Handling:** Alerts users when input fields are empty or when network requests fail.
* **Dynamic DOM Manipulation:** UI updates seamlessly on the fly without page reloads.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic markup and layout architecture.
* **CSS3** – Styling, layouts, and responsive design.
* **JavaScript (ES6+)** – Asynchronous API calls, DOM management, and event handling.
* **Fetch API & Async/Await** – Efficient asynchronous data fetching.
* **WeatherAPI** – External service integration for live meteorological data.
